# Vela i18n 覆盖度报告（决策前置事实）

> Status: Analysis
> Date: 2026-08-23
> Scope: 为「C3 本地化基础设施」的产品决策提供事实基线（谁来决定 English 的完整产品地位）

## 1. 现状测量（脚本统计，2026-08-23）

- **含中文的文件**：129 / 194（含字符串、数据与少量注释）
- **L10n.t 双语包装调用**：226 处（此前报告 300 处为含翻译表行的近似值；此处按调用点精确统计）
- **硬编码中文行**：约 4,601 行（保守口径：剔除纯注释行）
- **翻译覆盖率**：L10n 包装覆盖的文件 27 个；**剩余 102 个文件在英文模式下仍显示中文**，覆盖主屏 Today/Trends/Vela/Training 与 Coach/TrainingIntelligence 全域

## 2. 三个方案与代价

| 方案 | 内容 | 工作量级 | 风险 |
| :--- | :--- | :--- | :--- |
| **A. 完整系统本地化**（.xcstrings + 全量抽取） | 抽取 4,601 行中文为 key，英文为 source、中文为翻译；**移除 in-app 语言切换**，跟随系统 | 大型（数天-数周；4,601 行逐条审校 + UI 布局复验） | 行为变化：用户惯用 in-app 切换将失效；视觉回归风险大 |
| **B. 双轨制**（保留 in-app 切换 + L10n 覆盖全 UI） | 维持现有封装，把 102 个文件的硬编码中文全部转入 L10n.t（英/中成对） | 大型（同上量级，但无 UI 架构变化） | 低行为风险，高机械工作量；翻译维护靠源码内联 |
| **C. 维持现状（中文优先）** | English 定位为 Beta：设置页文案已如实说明「部分页面仍为中文」 | 0 | 与 PRD「Primary User 中文作者」一致；English 完整化无产品收益 |

## 3. 建议

**选 C（维持现状）并正式归档**——理由：
1. PRD 的 Primary User 是中文母语作者，北极星与用户体验都围绕中文；
2. 完整 English 化（A/B）需要数周且无对应产品收益（无英文用户目标）；
3. 已完成的卫生项保持：**未手动选择时跟随系统语言**（中文用户自动中文、英文系统回退英文）、设置页对 Beta 状态的如实说明；
4. 若未来出现英文用户诉求，方案 B 是低风险升级路径（A 的架构性变化收益有限）。

## 4. 此项的完成态定义

C3 以「文档化产品决策 + 已修复的系统语言跟随缺陷」为完成态；是否推进 A/B 由产品节奏决定。
