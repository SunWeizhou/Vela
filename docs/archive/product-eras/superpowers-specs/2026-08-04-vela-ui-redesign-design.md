# Vela 整体 UI 重设计（Apple HIG · 亮色 + 品牌绿）

- 日期：2026-08-04
- 状态：方向已获用户确认（细节后续迭代）
- 范围：Vela iOS 全部 4 个主页面 + 体征二级页 + 设计 Token

## 1. 背景与目标

用户对当时 UI 的反馈：不够美观大气、文字提醒不合理、指标可视化不美观、配色不好看、各页面设计语言不统一。目标：按 Apple Human Interface Guidelines 重制一套**统一、克制、有品牌辨识度**的设计语言，并借此收敛几个一直悬而未决的功能定位问题。

经可视化样稿（visual companion）多轮迭代，方向已锁定。

## 2. 设计语言决策（已确认）

### 2.1 主题：亮色为主
- 用户明确否定暗色调，采用**亮色为主**的设计。
- 深色模式保留适配（品牌绿在深色下提亮为 `#3FC97F`），但浅色是主战场，深色细节后续打磨。

### 2.2 品牌色：活力绿
对标「微信绿 / 支付宝蓝 / Claude 橙」，Vela 确立**品牌绿**（健康、恢复、活力的通用色，与警告色天然区分）：

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `brand` | `#17A35C` | `#3FC97F` | 主品牌色：hero 数字、CTA、Coach 入口、选中态、同步点 |
| `brandBright` | `#46C87E` | — | 渐变起点（`#46C87E → #17A35C`） |
| `brandDeep` | `#0C7A44` | — | 按压态 / 深色文字 |
| `brandSoft` | `#E3F2EA` | — | 浅绿填充底（头像底、徽章、建议块） |

### 2.3 指标着色：状态色（G1 方案）
指标圆环**不按指标身份配色，而按状态配色**——颜色只表达「好不好」，不装饰：

| 状态 | 颜色 | 触发 |
|---|---|---|
| 好 good | `#17A35C`（=品牌绿） | 分数处于健康区间 |
| 注意 moderate | `#E8A23C`（暖橙） | 中等 / 接近阈值 |
| 差 poor | `#E2607A`（玫红） | 明显偏离基线 |

效果：状态好的一整天整屏皆绿（品牌感拉满），需要留意的项用暖橙/红一眼跳出。原 `recoveryColor/sleepColor/...` 五个身份色在主视图**弃用**（仅在确需区分子项处保留，如睡眠阶段条用绿色系深浅）。

### 2.4 字体
- **大数字**：SF Pro Rounded（更运动、亲和），weight 800，紧缩字距，`monospacedDigit` 等宽对齐。
- **中文**：系统苹方，标题 700 / 正文 500 拉开字重对比。
- 收敛为一套清晰字阶：display(56–64) / metricValue(22–24) / cardTitle(15) / sectionTitle(13) / body(12) / label(10)。

### 2.5 画布与卡片
- 画布 `bg`：浅 `#F4F7F5` / 深 `#0B0F0C`；卡片 `cardBg`：浅 `#FFFFFF` / 深 `#151A16`。
- 文字：`fg #141A16`、`fg2 #6E766F`、`muted #9AA39B`。
- 卡片：细描边 `#E6EBE6` + 极浅投影，连续大圆角（18–22）。

## 3. 页面设计

### 3.1 今日（旗舰页）
自上而下：
1. **顶栏**：左 = 日期（可点选日历）+ 天气胶囊紧随其后；右 = 分享 + **头像**（点进「我的」）。头像右下角小绿点 = 已同步（取代原文字「已同步」）。
   - **去掉「训练状态」胶囊**（功能精简，见 §5）。
2. **Hero**：大号就绪度（渐变绿）+ READY 状态 + 7 天趋势小线。
3. **五指标状态色环**：恢复/睡眠/负荷/压力/能量，按 §2.3 状态色。
4. **今日指导卡**：洞察陈述 + 「和 Coach 聊聊 →」。**去掉「开始训练 xxx」按钮**（见 §5）。
5. **体征 2×2 大卡**：HRV/静息心率/血氧/睡眠。每张带迷你可视化——前三者趋势小线，睡眠用「深/浅/REM/清醒」阶段条。全部可点进二级页。
   - 对齐规则：固定标签高度 + 数值同一基线 + 单位统一缩小。
6. **本周负荷柱状图**（含 ACWR）。
7. **保留**：右滑切换前一天数据面板、天气、头像。

### 3.2 体征二级页（Bevel 式，统一模板）
HRV / 静息心率 / 血氧 / 睡眠 / 呼吸 / 腕温等**每项都有独立详情页**：
- 大数值 + 状态胶囊（如「▲ 高于基线」）
- 30 天趋势图（含个人正常区间阴影 + 基线虚线）
- 今日 / 7 天均值 / 30 天基线 对比
- 「如何解读」说明卡
- 「和 Coach 分析」入口 + 关联指标

### 3.3 训练（重定位）
配合「数据来自 Apple Health」的新定位：
- 训练负荷指标：ACWR / ATL / CTL / TSB
- 今日建议卡（基于恢复/TSB）+ 「和 Coach 讨论训练」
- **最近训练列表：来自 Apple 健康 / Fitness**（类型、时长、负荷、心率），每条可点进分析
- 底部注明「训练记录自动同步自 Apple 健康」
- **去掉所有「记录训练 / 开始训练」入口**
- 细节（数据排列与展示）**后续打磨**（用户确认可后续更新）。

### 3.4 教练
聊天气泡（绿=用户、白卡=Coach）+ 基于数据的建议 + 快捷提问 chips + 输入栏。视觉换新，交互逻辑不变。

### 3.5 我的
个人资料卡（头像 + 连续记录天数）+ 分组设置列表（健康数据源/通知/外观/记忆与Wiki/隐私/关于），彩色小图标 + 白卡。

## 4. 设计 Token 落地（VelaTheme）
在 `VelaApp/Core/Theme/VelaTheme.swift` 新增/调整：
- 新增 `brand / brandBright / brandDeep / brandSoft`、状态色 `stateGood/stateModerate/statePoor`、新画布与卡片色、SF Rounded 数字字体方法（如 `displayValue()`、`metricValue()`）。
- 保留旧 Token 别名做向后兼容，逐步收敛（硬编码收敛约 1357 处，见「后续」）。
- 指标环/体征卡/趋势图在 `VelaDesignSystem` 新增对应组件（`VelaMetricScoreRing` 支持状态色）。

## 5. 功能范围决策（借此次重设计一并确认）
- **放弃 App 内「训练时记录」**：训练数据改用**已同步的 Apple Health / Fitness 记录**（`HealthKitSyncEngine` 已在同步 workout），供分析与 Coach 讨论。去掉记录入口与「开始训练」CTA。
- **去掉「训练状态」胶囊**。
- **今日指导**定位从「行动入口」转为「洞察 + Coach 讨论入口」。
- 以上精简与既有特性开关思路一致：优先用 `VelaFeatureFlags` 隐藏入口、保留底层代码，可逆。

## 6. 实施约束
- **绝不脚本修改 pbxproj**：新代码加入现有文件或按 Minimal Shell 文件映射覆盖；新文件由用户在 Xcode 手动注册。
- 保持 274 测试全绿；每阶段 `xcodebuild` 编译通过 + 真机目视确认。
- 大改动用特性开关包裹，可逆。

## 7. 分阶段实施（增量、每步可验证）
- **P0 设计 Token**：VelaTheme 新品牌绿/状态色/字阶（纯增量，低风险）。
- **P1 今日页**：顶栏、hero、状态色环、指导卡、体征 2×2、本周负荷、保留天气/右滑/头像。
- **P2 体征二级页**：统一模板 + 各指标接入。
- **P3 训练页重定位**：负荷指标 + Apple 健康训练列表 + 去记录入口。
- **P4 教练 / 我的页**：视觉统一。
- **P5 收尾**：去训练状态、细节打磨、硬编码 Token 收敛。

## 8. 后续（用户确认可 deferred）
- 训练页数据排列与展示的细节打磨。
- 全 App 硬编码颜色/字号/圆角收敛到 Token（`scripts/audit_design_tokens.sh` 报告约 1357 处）。
- 深色模式的精细打磨。

## 9. 成功标准
- 各页面共用同一套 Token 与组件，设计语言统一。
- 配色收敛为「白 + 品牌绿 + 状态色」，无彩虹感。
- 大数字用 SF Rounded，字阶清晰，无文字堆砌。
- 体征对齐且有二级页；训练页不再要求手动记录。
- 274 测试保持全绿。
