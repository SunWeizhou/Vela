# Treat eating as behavioral context before nutrition accounting

Vela will primarily help the user recognise and recover from changes in Eating Rhythm rather than operate as a mandatory calorie and macronutrient tracker. A quick report can identify normal eating, overeating, binge eating, skipped meals, or irregular eating; photos, foods, portions, calories, and nutrients remain optional Meal Detail. Existing nutrition-analysis capabilities may support deeper investigation, but they must not become a daily logging requirement, a primary Today module, or a basis for Compensatory Actions.
