# Let AI propose plan changes but require user confirmation

Deterministic local evidence and rules ensure that a canonical Daily Operating Plan exists every day and establish its safety constraints. AI organizes and expresses that plan in natural language, interprets free-form life context, identifies candidate patterns, compares alternatives, and may create a Plan Proposal, but it may not silently override scored evidence, safety boundaries, or the persisted plan. The user may directly edit, delete, reschedule, or replace plan actions. A later material AI-suggested change must present a diff and becomes canonical only after explicit user confirmation; this preserves local availability, auditability, and user agency while still using AI for the ambiguous reasoning it handles well.
